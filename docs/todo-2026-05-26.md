## T1 — 修正員工搜尋 404 (`/api/employees/search`)

> `training.js` 中有兩處 `fetch` 呼叫未使用 `BASE` 前綴，直接寫死路徑。
> `Program.cs` 設定 `UsePathBase("/tcs")`，Razor Layout 對應設定 `window.ERP_BASE = '/tcs'`，
> 導致這兩處呼叫不帶 `/tcs` 前綴，命中不存在的路由而回傳 404。

### 根本原因

`src/TCS.Web/wwwroot/js/training.js`：

| 行數 | 現狀（錯誤） | 應改為 |
|---|---|---|
| 169 | `` fetch(`/api/employees/search?q=${...}`) `` | `` fetch(`${EMPLOYEE_API}/search?q=${...}`) `` |
| 258 | `` fetch(`/api/employees/${encodeURIComponent(item.EmployeeId)}`) `` | `` fetch(`${EMPLOYEE_API}/${encodeURIComponent(item.EmployeeId)}`) `` |

`EMPLOYEE_API` 已於第 4 行定義為 `BASE + '/api/employees'`，統一使用即可。

### [T1-1] 修正 `training.js` 兩處硬編碼路徑

- [x] 將 `training.js:169` 改為 `` `${EMPLOYEE_API}/search?q=${encodeURIComponent(q)}` ``
- [x] 將 `training.js:258` 改為 `` `${EMPLOYEE_API}/${encodeURIComponent(item.EmployeeId)}` ``

### [T1-2] 驗證

## T2 — `TrainingDetail.Hours` 改為 nullable (`decimal?`)

> schema.json 由程式碼產生，`TB005 nullable: false` 反映 C# `decimal Hours`（值型別）。
> 決定改為 `decimal?`，允許訓練紀錄建立時不填時數、事後補入。
> DB 欄位由使用者自行 ALTER TABLE，不跑 EF Migration。

### [T2-1] Entity — `src/TCS.Core/Entities/TrainingDetail.cs`

- [x] `decimal Hours` → `decimal? Hours`

### [T2-2] DTO — `src/TCS.Core/DTOs/TrainingDetailDto.cs`

- [x] `decimal Hours` → `decimal? Hours`（record positional parameter）

### [T2-3] Request — `src/TCS.Core/DTOs/Requests/CreateTrainingDetailRequest.cs`

- [x] `decimal Hours` → `decimal? Hours`

### [T2-4] Request — `src/TCS.Core/DTOs/Requests/UpdateTrainingDetailRequest.cs`

- [x] `decimal Hours` → `decimal? Hours`

### [T2-5] Validator — `src/TCS.Core/Validators/Training/CreateTrainingDetailValidator.cs`

- [x] 改為「有值才驗範圍」：
  ```csharp
  RuleFor(x => x.Hours)
      .GreaterThan(0m).WithMessage("受訓時數必須大於 0")
      .LessThanOrEqualTo(9999.9m).WithMessage("受訓時數不可超過 9999.9")
      .When(x => x.Hours.HasValue);
  ```

### [T2-6] Validator — `src/TCS.Core/Validators/Training/UpdateTrainingDetailValidator.cs`

- [x] 同 T2-5，加上 `.When(x => x.Hours.HasValue)`

### [T2-7] DB（使用者自行執行）

- [ ] `ALTER TABLE TCSTB ALTER COLUMN TB005 decimal(6,1) NULL`
