## T3 — 系統欄位自動填入（SaveChanges 攔截器）

> 目前 `AppDbContext` 沒有 `SaveChangesAsync` 覆寫，系統欄位（Creator、CreateDate、
> Modifier、ModiDate、COMPANY、USR_GROUP、Flag）在任何 CRUD 操作中從未被填入，
> 導致 DB 中這些欄位永遠為 null。
> 應在 DbContext 層統一攔截，避免每個 Service 分散處理。

### [T3-1] 後端 `src/TCS.Infrastructure/Data/AppDbContext.cs`

- [ ] 注入 `ICurrentUserService`（來自 `ERP.Auth.Common`）
- [ ] 覆寫 `SaveChangesAsync`：
  ```csharp
  public override Task<int> SaveChangesAsync(CancellationToken ct = default)
  {
      var now = DateTime.Today.ToString("yyyyMMdd");
      var user = _currentUserService.UserId ?? "SYSTEM";
      var company = _currentUserService.Company ?? "";  // 依 JWT claims 定義
  
      foreach (var entry in ChangeTracker.Entries<IAuditableEntity>())
      {
          if (entry.State == EntityState.Added)
          {
              entry.Entity.Creator = user;
              entry.Entity.CreateDate = now;
              entry.Entity.Company = company;
              entry.Entity.Flag ??= 0;
          }
          if (entry.State is EntityState.Added or EntityState.Modified)
          {
              entry.Entity.Modifier = user;
              entry.Entity.ModiDate = now;
          }
      }
      return base.SaveChangesAsync(ct);
  }
  ```
- [ ] 確認 `ICurrentUserService` 有提供 `UserId`、`Company`（視 ERP.Auth.Common 的實作決定欄位名稱）
- [ ] 若 `ICurrentUserService` 尚無 `Company` / `UsrGroup` 屬性，與 ERP.Auth.Common 協調補充
