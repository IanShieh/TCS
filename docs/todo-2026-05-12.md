> `--bs-table-bg-state` 在 `<td>` 層設定背景；目前兩個頁面的 CSS 都寫在 `<tr>` 上
> （`tr.row-selected { background-color: #cfe2ff }`），被 `<td>` 的 CSS 變數覆蓋，視覺上沒有任何變化。
> `box-shadow: inset` 寫在 `<tr>` 亦因 `border-collapse` 被截斷而不可見。
