## T1 — 證照主檔新增對話框：選擇「對應大類」時自動推算下一個序號

> 使用者選擇 `#m-Category` 下拉後，系統應自動帶入 `#m-LicenseType` 的值：
> - 選「大類」sentinel → 推算下一個整數（現有最大整數 + 1）
> - 選現有大類（如「2 安全類」）→ 推算該大類下一個小類代碼（如已有 2.1、2.2 則填 2.3）
> **`#m-LicenseType` 欄位應設為 `disabled`（不可手動修改）**；代碼完全由系統依所選大類推算決定。

### [T1-1] 前端 `license.js`

- [x] 在 `cachedAllCategories` 宣告旁新增 `let cachedAllLicensesFull = null;`（快取全部證照，含小類）
- [x] 修改 `ensureAllCategoriesLoaded()`：在 `data.Items` 取回後，
  先將完整結果存入 `cachedAllLicensesFull = data.Items || []`，
  再以現有 `filter(x => x.IsCategory || INTEGER_REGEX.test(x.LicenseType))` 計算 `cachedAllCategories`
- [x] 新增函式 `suggestNextLicenseType(selectedCategory)`：
  - 若 `selectedCategory === '__MAJOR__'`：
    ```js
    const majors = cachedAllLicensesFull
        .filter(x => INTEGER_REGEX.test(x.LicenseType))
        .map(x => parseInt(x.LicenseType, 10));
    return String(majors.length ? Math.max(...majors) + 1 : 1);
    ```
  - 若為現有大類代碼（如 `"2"`）：
    ```js
    const subs = cachedAllLicensesFull
        .filter(x => x.Category === selectedCategory)
        .map(x => {
            const parts = x.LicenseType.split('.');
            return parseInt(parts[parts.length - 1], 10);
        })
        .filter(n => !isNaN(n));
    const nextIdx = subs.length ? Math.max(...subs) + 1 : 1;
    return `${selectedCategory}.${nextIdx}`;
    ```
  - 否則回傳 `''`（不建議）
- [x] 在 `$('#m-Category').on('change', ...)` handler（`openLicenseModal` 的 init 區段，目前只有 `syncCategoryVisibility` 綁在 `#m-LicenseType input`）新增：
  ```js
  $('#m-Category').on('change', function () {
      const val = $(this).val();
      const suggested = suggestNextLicenseType(val);
      if (suggested) {
          $('#m-LicenseType').val(suggested).prop('disabled', true);
      } else {
          $('#m-LicenseType').val('').prop('disabled', false);
      }
      syncCategoryVisibility();
  });
  ```
- [x] `openLicenseModal('create')` 初始化時，`#m-Category` 預設為「-- 請選擇 --」（val = `''`）→ `#m-LicenseType` 維持 `disabled: false`、值清空
- [x] 確認 `openLicenseModal('create')` 呼叫 `await ensureAllCategoriesLoaded()` 已完成後才填充下拉（現有已是 async；加上 `await` 確保 `cachedAllLicensesFull` 就緒）

## T2 — 「對應大類」下拉選單新增「大類」特殊選項

### [T2-1] 前端 `license.js`

- [x] 修改 `populateCategoryOptions()`，在「-- 請選擇 --」之後、現有大類列表之前插入：
  ```js
  $('<option></option>').val('__MAJOR__').text('大類').appendTo($sel);
  ```
- [x] 修改 `syncCategoryVisibility()`：Category wrap **永遠顯示**（不隱藏，避免使用者選了「大類」後無法切換回其他選項）；
  改為只控制 Hours/Years 的必填狀態
  ```js
  function syncCategoryVisibility() {
      const v = $('#m-LicenseType').val();
      const categoryIsMajor = $('#m-Category').val() === '__MAJOR__';
      const ltIsMajor = isLicenseTypeMajor(v);
      $('#m-Category-wrap').show(); // 永遠顯示
      if (ltIsMajor || categoryIsMajor) {
          $('#m-Hours-required, #m-Years-required').addClass('d-none');
          $('#m-Hours, #m-Years').prop('required', false);
      } else {
          const minor = isLicenseTypeMinor(v);
          $('#m-Hours-required, #m-Years-required').toggleClass('d-none', !minor);
          $('#m-Hours, #m-Years').prop('required', minor);
      }
  }
  ```
- [x] `openLicenseModal('edit', item)`：若編輯的是大類（LicenseType 為整數），`#m-Category` 預設選「大類」（`__MAJOR__`），而非空白
- [x] `submitLicense` 中 `Category` 取值需排除 sentinel：
  目前為 `Category: isMajor ? null : ($('#m-Category').val().trim() || null)`；
  修改為：
  ```js
  const catVal = $('#m-Category').val();
  Category: (isMajor || catVal === '__MAJOR__') ? null : (catVal.trim() || null),
  ```

  async function loadPlantOptions(licenseType) {
      const $sel = $('#m-Plant').empty();
      $('<option></option>').val('').text('（不選廠別）').appendTo($sel);
      if (!licenseType) return;
      const res = await fetch(LICENSE_PLANT_API(licenseType));
      if (!res.ok) return;
      const items = await res.json();
      items.forEach(p => {
          const label = p.PlantName ? `${p.Plant} ${p.PlantName}` : p.Plant;
          $('<option></option>').val(p.Plant).text(label).appendTo($sel);

  }
