- [ ] 表格下方加入**廠別需求子表**（LicensePlantRequirement）：

  - 子表欄位：廠別代碼、廠別名稱、需求數
  - 子表操作按鈕：`[+] [✎] [✗]`，各自 Modal
- [ ] 刪除已不需要的 `LicenseViewController.Create()` / `Edit()` action
- [ ] 刪除 `Views/License/Create.cshtml`、`Views/License/Edit.cshtml`
