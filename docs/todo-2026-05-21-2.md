## T1 — 資料表改名（TRNM01→TCSMA / TRNM02→TCSMB / TRNF01→TCSTA / TRNF02→TCSTB）

> 原始規格（`schema copy.json`）定義資料表為 TCSMA/TCSMB/TCSTA/TCSTB，但 EF 初始設定誤用 TRNM01 等名稱。  
> 正確做法是用 Migration 將資料表改名，而非修改規格文件。

### [T1-1] EF Configuration — 4 個設定檔

- [ ] `LicenseMasterConfiguration.cs`：`builder.ToTable("TRNM01")` → `builder.ToTable("TCSMA")`
- [ ] `LicensePlantRequirementConfiguration.cs`：`builder.ToTable("TRNM02")` → `builder.ToTable("TCSMB")`
- [ ] `TrainingHeaderConfiguration.cs`：`builder.ToTable("TRNF01")` → `builder.ToTable("TCSTA")`
- [ ] `TrainingDetailConfiguration.cs`：`builder.ToTable("TRNF02")` → `builder.ToTable("TCSTB")`

### [T1-2] EF Migration — 新增改名 Migration

- [ ] 執行：
  ```
  dotnet ef migrations add RenameTablesFromTRNToTCS --project src/TCS.Infrastructure --startup-project src/TCS.Web
  ```
- [ ] 確認產生的 Migration `Up()` 包含以下 4 筆 `RenameTable`：
  ```csharp
  migrationBuilder.RenameTable(name: "TRNM01", newName: "TCSMA");
  migrationBuilder.RenameTable(name: "TRNM02", newName: "TCSMB");
  migrationBuilder.RenameTable(name: "TRNF01", newName: "TCSTA");
  migrationBuilder.RenameTable(name: "TRNF02", newName: "TCSTB");
  ```
- [ ] 確認 `Down()` 包含相反的 4 筆 `RenameTable`（TCSMA→TRNM01 等）

> **注意**：FK constraint 名稱（如 `FK_TRNF01_TRNM01_LicenseType`）在改名後可能需要手動更新。若 EF 未自動處理，需在 Migration 中手動 `DropForeignKey` + `AddForeignKey`。

### [T1-3] schema.json — 還原資料表名稱

- [ ] 將 `schema.json` 4 個 table 的 `"table"` 欄位還原為：
  - `"TRNM01"` → `"TCSMA"`
  - `"TRNM02"` → `"TCSMB"`
  - `"TRNF01"` → `"TCSTA"`
  - `"TRNF02"` → `"TCSTB"`
- [ ] 同步更新 `schema.json` 的 `relationships` 區段中的 `references_table` 欄位

> **欄位名稱說明**：`schema.json`（及 `schema copy.json`）使用 ERP 代碼式欄位名（MA001、MB001…），實際 DB 欄位名與 EF 屬性名相同（LicenseType、Description…）。此差異已知，暫不在本次 TODO 對齊，需另行規劃。

### [T1-4] 執行 DB 更新

- [ ] `dotnet ef database update --project src/TCS.Infrastructure --startup-project src/TCS.Web`
- [ ] 至 SQL Server 確認 4 張資料表已改名

### [T1-5] 驗證

- [ ] `dotnet build` 0 errors
- [ ] `grep -r "TRNM01\|TRNM02\|TRNF01\|TRNF02" src/` 無任何輸出（確認舊名稱已完全清除）
- [ ] API 呼叫正常（資料表改名後不影響 EF 屬性名與商業邏輯）

## T2 — 新增 TrainingHeader.RequiredYears 欄位

> `LicenseMaster.Years`（有效年限）在建立 TrainingHeader 時應同步帶入並儲存為 `RequiredYears`，  
> 與現有 `RequiredHours` 模式一致，建立後唯讀。  
> 目前 `MappingExtensions.ToDto()` 計算 `NextReviewDate` 時直接讀取 `licenseMaster?.Years`（navigation property），  
> 改為使用 `header.RequiredYears` 可消除對 LicenseMaster nav 的依賴，邏輯更健壯。

### [T2-1] Entity — `src/TCS.Core/Entities/TrainingHeader.cs`

- [ ] 新增屬性（接在 `RequiredHours` 下方）：
  ```csharp
  public int? RequiredYears { get; set; }   // 建立時從 LicenseMaster.Years 帶入，唯讀
  ```

### [T2-2] EF Configuration — `src/TCS.Infrastructure/Configurations/TrainingHeaderConfiguration.cs`

- [ ] 新增欄位對應（接在 `RequiredHours` 之後）：
  ```csharp
  builder.Property(e => e.RequiredYears).IsRequired(false);
  ```

### [T2-3] EF Migration

- [ ] 執行：
  ```
  dotnet ef migrations add AddRequiredYearsToTrainingHeader --project src/TCS.Infrastructure --startup-project src/TCS.Web
  ```
- [ ] 確認 Migration `Up()` 包含（table 名依 T1 完成狀況，若 T1 先做則為 `TCSTA`，否則為 `TRNF01`）：
  ```csharp
  migrationBuilder.AddColumn<int>(
      name: "RequiredYears",
      table: "TCSTA",   // 或 "TRNF01"
      type: "int",
      nullable: true);
  ```

### [T2-4] Service — `src/TCS.Core/Services/TrainingService.cs`

- [ ] `CreateHeaderAsync()` 中，在 `RequiredHours = license.Hours ?? 0` 下方新增：
  ```csharp
  RequiredYears = license.Years,
  ```

### [T2-5] DTO — `src/TCS.Core/DTOs/TrainingHeaderDto.cs`

- [ ] 在 `RequiredHours` 參數後新增：
  ```csharp
  int? RequiredYears,
  ```

### [T2-6] Mapping — `src/TCS.Core/Mapping/MappingExtensions.cs`

- [ ] 將 `nextReviewDate` 計算從 `licenseMaster?.Years` 改為 `header.RequiredYears`：
  ```csharp
  // 改前
  DateOnly? nextReviewDate = latestAcquireDate.HasValue && licenseMaster?.Years.HasValue == true
      ? latestAcquireDate.Value.AddYears(licenseMaster.Years!.Value)
      : null;

  // 改後
  DateOnly? nextReviewDate = latestAcquireDate.HasValue && header.RequiredYears.HasValue
      ? latestAcquireDate.Value.AddYears(header.RequiredYears.Value)
      : null;
  ```
- [ ] `return new TrainingHeaderDto(...)` 呼叫中，在 `header.RequiredHours` 後加入 `header.RequiredYears`

### [T2-7] 執行 DB 更新

- [ ] `dotnet ef database update --project src/TCS.Infrastructure --startup-project src/TCS.Web`

### [T2-8] 驗證

- [ ] `dotnet build` 0 errors
- [ ] 新增 TrainingHeader → DB 確認 `RequiredYears` 欄位有值（與 LicenseMaster.Years 一致）
- [ ] LicenseMaster.Years 為 null 時，`RequiredYears` 儲存 null，`NextReviewDate` 回傳 null（不崩潰）
